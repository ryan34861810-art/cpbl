# cpbl

## 球日誌｜棒球歷史上的今天

繁體中文靜態網站，使用 HTML、CSS 與原生 JavaScript，無須安裝套件或執行建置。

- 首頁依訪客裝置日期顯示棒球歷史事件。
- 日曆可切換月份，紅點代表有收錄故事，點選日期可閱讀事件。
- 40 篇 DAZN 專欄可依關鍵字及月份搜尋。
- 支援手機版面與事件詳情視窗。

## 預覽與內容更新

下載所有檔案後，用瀏覽器開啟 index.html。Google Fonts 無法連線時會使用系統字型。

事件資料位於 events.js。每筆包含唯一數字 id、year、date（MM/DD）、title、url。無文章的事件可將 url 設為空字串，加入 description 作為完整介紹；日曆詳情會顯示介紹。新增事件時請同步更新 index.html 中的典藏總數。

## 部署

可匯入支援靜態網站的託管平台，不需建置指令，發布目錄為儲存庫根目錄。上傳 GitHub 並不代表已上線。

GitHub Pages 可在 Settings → Pages 選擇從 main 分支根目錄發布。私人儲存庫的 Pages 可用性取決於 GitHub 方案與政策；請在發布前確認公開範圍。
